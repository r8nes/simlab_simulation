# Godland — World Simulation

A living world simulation from **Godland**, a Unity roguelike where the player is a *writer*, not a god.

**What it simulates.** A small tile world over ~3000 years. Settlements grow and starve, faiths spread and split, cities form kingdoms and wage wars, and gods, titans, heroes and new races are born and fall. Epochs shift, catastrophes and sagas reshape the land, and creatures evolve through their genes.

**How it works.** Nothing is scripted. Every actor picks actions from its temperament and situation, using learning minds, goal planning and simple genetics. The world remembers past events and reacts to them. The same seed always gives the same world.

**SimLab** is a test bench with no graphics. Set the world's parameters, run the simulation and read the event log.

*Code only: graphics and paid plugins are not included.*
